# Practica Bootstrap

## Bootstrap 5 Grid Practice

Use this checklist to build your assignment one step at a time. Keep the layout in your own hands and commit after each meaningful milestone.

### Roadmap

- [ ] **Start with the hierarchy:** add a `.container`, then a `.row`, then place `.col-*` elements inside the row. Keep columns as direct children of rows.
- [ ] **Practice the 12-column rule:** make one full-width column with `col-12` (12/12), then a `col-8` and `col-4` pair (8 + 4 = 12), then three `col-4` columns (4 + 4 + 4 = 12).
- [ ] **Add responsive behavior:** try breakpoint classes such as `col-md-*`. Compare how columns behave below and at the `md` breakpoint, and choose the sizes that fit your assignment.
- [ ] **Check your work:** resize the browser, inspect the page at narrow and wide widths, and confirm the column totals and nesting are intentional.

### Suggested Git Commits

Make small commits that show the learning progression:

1. `chore: add Bootstrap practice starter`
2. `practice: add container and row structure`
3. `practice: explore 12-column combinations`
4. `practice: add responsive md columns`
5. `style: refine custom grid practice`
